# Yousef Hamdy | CV website

A static personal CV website built with HTML and CSS and hosted on GitHub Pages.

**[View the website](https://yousefshehab1.github.io/cv-website/)**

## Files

| File | Purpose |
| --- | --- |
| `index.html` | CV sections and contact links |
| `style.css` | Page layout and styling |
| `photo.jpg` | Profile photograph |

## Preview locally

Clone the repository and serve it from its root:

```bash
git clone https://github.com/yousefshehab1/cv-website.git
cd cv-website
python -m http.server 8000
```

Open `http://localhost:8000`. There is no build step or application backend. The current page loads Font Awesome from an external CDN for icons.

## Updating the website

Edit `index.html` for content and links, and `style.css` for presentation. Check both desktop and mobile layouts and verify contact and project links before publishing.

The repository README documents the site; it is not the CV itself. This documentation update does not change the live CV's wording or qualifications. The existing site content is being reviewed separately for a current portfolio revision.

## Privacy

This is a public website. Only publish contact details and documents intended to be visible to visitors. Never add credentials, private addresses or account tokens.
